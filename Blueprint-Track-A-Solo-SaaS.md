# 1. Resumen

## Problema
El cliente paga, pero no entiende qué compró ni qué hacer primero → no usa el producto.

## Resultado de la primera sesión (45 min)
- Conversación de negocio (arranque consultivo)
- Configuración según el tiempo
- Prioridad anotada en tareas B2B3+ (Company Management)
- **Acción de uso realizada por el cliente** o compromiso concreto para las próximas 48–72 h
- **Próxima (2ª) sesión agendada**

El cliente debe sentir que AgendaPro entiende su negocio y resuelve con él.

## De pago a primera sesión

```
Cliente paga
  → ISR: WhatsApp de bienvenida (credenciales + datos del owner + horarios)
       + nota en HubSpot — sin formulario POS/boletas
  → ISR: agenda la Asesoría 1 en el calendario del owner
       (no le pasa el link al cliente)
       Evento: "Asesoría 1" + ID · máximo 48 horas hábiles
  → ISR: crea el canal (Chatwoot o WhatsApp) + pase
  → Owner confirma recepción
  → Primera sesión (Owner): este blueprint
```

## Señales de que el proceso va bien
| Señal | Dónde |
|-------|--------|
| 4 temas + espejo | Diio |
| Prioridad en B2B3+ | Company Management |
| Acción de uso o compromiso ≤72 h | Cuenta + tarea B2B3+ |
| Próxima sesión agendada | Calendario |
| Configurar a los ~10 min sin espejo | Alerta en Diio |

## 4.1 Formato mínimo del registro B2B3+

Escribir en la tarea, con lenguaje simple y suficiente para que otro pueda retomar el caso:

| Campo | Qué registrar |
|---|---|
| Prioridad | Qué quiere resolver el cliente, en sus palabras |
| Acción | Qué se configuró o hará el cliente |
| Responsable | Cliente, owner u otra persona |
| Fecha | Cuándo se revisa: 2ª sesión o control |
| Señal de uso | Reserva de prueba, link publicado, horario cargado u otra evidencia concreta |

# 5. Éxito al cerrar la primera sesión

1. Entiende qué compró  
2. Tiene un plan corto  
3. Prioridades claras  
4. Puede decir cómo AgendaPro le ayuda  
5. Tiene **próxima sesión agendada**  
6. Se siente acompañado (humano + resolutivo + aliado)  
7. Realizó una acción de uso o quedó con un compromiso específico para las próximas 48–72 h  

No hace falta terminar toda la agenda matriz en la primera llamada.

---

# 6. Cómo va la reunión (45 min; +10 si hay varias sedes)

```
A. Arranque ~15 min → B. Configurar → C. Cierre 3–5 min
```

### A — Arranque
- **Encuadre:** “Hoy vamos a alinear prioridades y avanzar juntos.”  
- **4 temas** (en conversación, sin anunciar un cuestionario): por qué compró · qué le duele · cómo lo hacía · quién opera.  
- **Espejo (~45 s):** “Si entendí bien… ¿priorizamos X?”  
- **Anotar** en B2B3+ (Company Management) con el formato §4.1.  
- Tono humano + avanzar con lo acordado.

### B — Configurar
Sedes → profesionales → horarios → servicios → permisos → link / prueba si alcanza. Si no alcanza, dejar la acción de uso específica para las próximas 48–72 h en B2B3+.

### C — Cierre
Repasar éxito · confirmar acción de uso/compromiso · agendar próxima sesión · tareas con responsable y fecha.

**Evitar:** “vamos a hacerles 4 preguntas” · configurar sin espejo · abrir POS/boletas.

---

# 7. Si aún no hubo primera sesión

- Sin contacto tras 48 h → el **owner** insiste (el canal ya existe).  
- No asiste → el **owner** reprograma.  
- Intentos del ISR quedan en HubSpot.

# 8. Casos especiales

| Si… | Entonces… |
|-----|-----------|
| Cliente apurado | 8–10 min a los 4 temas + espejo; configurar lo esencial; resto a la próxima |
| Aparece POS/boletas en el chat | Parar → Ruta B o avisar al líder |
| Solo está la recepción | Simplificar; acordar quién completa tareas |
| Varias sedes | +10 min; no saltar espejo ni cierre |
| No llegan reservas / no está listo el link | Revisar link público, horarios, servicios y responsable; dejar una acción usable hoy y control ≤72 h |
| Migración pesada / muchos datos | Priorizar lo mínimo para operar; acordar qué completa cada parte y fecha de revisión |
| Cobros, factura o cuenta anterior | Derivar al responsable, informar al cliente quién sigue y volver al plan de uso de Ruta A |

# 10. Ejemplo bueno / malo

**Bien:** conversación de negocio → espejo → anotar B2B3+ completo → configurar según prioridad → acción de uso → próxima sesión.  
**Mal:** “vamos a configurar” sin escuchar · o tratar un caso POS como Solo SaaS.

# 11. Auditoría de calidad (Diio + Company Management)

**No es evaluación de desempeño.** Es la misma pauta para practicar y dar feedback.

| Criterio | 0 | 1 | 2 |
|---|---|---|---|
| Ruta correcta | No validó o mezcló Ruta B | Validó con duda sin escalar | Ruta A/B confirmada y trazable |
| 4 temas | Ausentes o cuestionario rígido | Parciales | Conversación fluida que cubre los 4 |
| Espejo | No ocurrió | Resumen sin prioridad | Resume y confirma prioridad |
| B2B3+ | Sin registro | Registro incompleto | Usa los 5 campos de §4.1 |
| Configuración | Genérica | Parcialmente ligada a prioridad | Responde a la prioridad acordada |
| Cierre | Sin siguiente paso | Solo 2ª o tareas | Acción de uso + responsable/fecha + próxima sesión |

**Cadencia de Habilitación:** cada semana, revisar 5 R1 por onboarder nuevo y 2 por onboarder con más experiencia. Registrar puntaje, un comportamiento a mantener y un cambio para la siguiente R1; luego mirar reservas a 14 días como señal de resultado.
