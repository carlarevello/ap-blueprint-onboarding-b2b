# 1. Portada holística (Track B)

## Problema
Comercios con hardware/fiscal mal traspasados o con R1 “como si fuera Solo SaaS” → demora de máquina, doble tributación, cliente confundido, Owner JR sobrecargado.

## Resultado
Traspaso **completo** (form recibido) + R1 orientada a **planificar implementación POS/FE** (y SaaS solo en lo necesario para operar) + journey POS/FE en marcha + próximos hitos claros.

## De pago a R1 (diferencias vs Solo SaaS)

```
Cliente paga (SaaS + POS y/o FE)
  → ISR: WhatsApp bienvenida
       + credenciales
       + FORMULARIO(S) POS/FE (enviar y confirmar recepción)
       + datos Owner + ofrece horarios
       + nota anclada HubSpot (checklist: POS/FE + qué se vendió)
  → ISR: agenda R1 en calendario Owner ("Asesoría 1" + ID) · SLA 48 h hábiles
  → ISR: crea Chatwoot o grupo WA con etiquetas POS / FE / sin SII (si aplica) + pase
  → Owner (habilitado Track B) confirma recepción y revisa form
  → R1 Track B (este Blueprint) — no usar kickoff Solo SaaS como guion principal
```

**Si falta el formulario:** traspaso **incompleto**. Igual se crea el chat; se registra en checklist HubSpot; **ISR insiste**. Sin form **no se solicita la máquina** → POS se retrasa. Owner no inventa el form.

# 6. Anatomía R1 Track B (orientativa)

**Duración:** 45–60 min si POS+boletas complejo; ajustar según procedimiento.

**No** abrir con el playbook Solo SaaS (15 min 4 temas + espejo como eje).  
**Sí** seguir el procedimiento POS+e-Boletas:

1. Confirmar dueño + quien opera caja  
2. Validar qué se vendió (solo POS / POS+boletas / Split / sin SII)  
3. Estado del form y bloqueos  
4. Plan: cobrar (POS) → fiscalizar (boletas)  
5. Próximas sesiones / despacho / autorizaciones (según país y procedimiento)  
6. SaaS de agenda: solo lo mínimo para no bloquear operación **si el tiempo alcanza** — sin convertir la R1 en setup SaaS completo

**Criterio de éxito Track B (R1):**
- Form y handoff claros (o hold explícito)  
- Cliente entiende qué es POS vs boletas y qué falta  
- Plan de implementación con responsables/fechas  
- Journey POS/FE actualizado  
- Próxima instancia agendada  

---

# 7. Caso especial — sin SII

Si contrata POS pero **sin inicio de actividades en SII**:
- Entra a Onboarding igual  
- Form igual (para solicitar máquina)  
- **No** configurar POS hasta inicio de actividades  
- Registrar en HubSpot fecha aproximada  
- Etiqueta **sin SII** (Chatwoot) o en descripción WA
